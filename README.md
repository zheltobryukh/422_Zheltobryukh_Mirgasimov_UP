### 💡 Особенности и Требования (согласно МУ)

Проект разработан с учетом следующих обязательных требований методических указаний:

* **Тип приложения:** Единый WPF-проект.
* **Система контроля версий:** Проект хранится в Git (GitHub).
* **Стилевое оформление:** Соответствует Словарю стилей (единый шрифт, одинаковые размеры элементов управления).
* **Навигация:** Заголовок каждой страницы (`Title`) содержит информацию о её содержимом (например, "Авторизация", "Регистрация", "Главное меню").
* **UX/UI:** Предусмотрены проверки формата вводимых данных, обратная связь с пользователем и всплывающие подсказки.

### 🚀 Установка и Запуск

Для запуска приложения необходимо наличие установленной среды **Microsoft Visual Studio** и соответствующего **.NET SDK**.

1.  **Клонирование репозитория:**
    ```bash
    git clone [https://github.com/zheltobryukh/422_Zheltobryukh_Mirgasimov_UP.git](https://github.com/zheltobryukh/422_Zheltobryukh_Mirgasimov_UP.git)
    cd 422_Zheltobryukh_Mirgasimov_UP
    ```

2.  **Открытие решения:**
    * Откройте файл `422_Zheltobryukh.sln` в Visual Studio.

3.  **Настройка Базы Данных:**
    *  Проверьте и при необходимости отредактируйте строку подключения (`Connection String`) в файле конфигурации.

4.  **Сборка и Запуск:**
    * Соберите решение (Build Solution) и запустите проект в режиме отладки (`F5`).
